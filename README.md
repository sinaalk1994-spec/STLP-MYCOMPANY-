# تهران‌ولت | Tehran Volt

اپ اندروید مخصوص مدیران اتحادیه باتری و برق خودرو تهران، متصل به **https://tehbatri.ir/admin**.

**[دانلود فایل نصب اندروید، نسخهٔ ۱.۰.۰](https://github.com/sinaalk1994-spec/STLP-MYCOMPANY-/raw/refs/heads/main/android/dist/TehranVolt-1.0.0.apk)**

![آیکون اپ](android/artwork/tehran-volt.png)

اندروید ۸ به بالا. پس از نصب، خودتان با حساب فعلی پنل وارد شوید. نام کاربری و رمز عبور در این مخزن قرار ندارد. اپ برای نمایش پنل اصلی و نگهداری نشست ورود، انتخاب و آپلود فایل و ذخیرهٔ PDF/اکسل طراحی شده است. منوی بالای اپ امکان بازگشت، بازخوانی، رفتن به پنل و چاپ/PDF صفحه را می‌دهد.

این مخزن شامل **کد مستقل اپ اندروید** است؛ کد ERP اصلی و اطلاعات اعضا در آن قرار نگرفته است.

کد با SDK 35 کامپایل شده، ۴۲ بررسی نشانی‌ها و نام فایل‌ها پاس شده و امضا و alignment فایل نصب تأیید شده است. **تست روی گوشی واقعی هنوز انجام نشده**؛ پس از نصب باید ورود، خروج، آپلود فایل و دریافت خروجی‌ها بررسی شوند. آیکون آیفون نیاز به انتشار جداگانه روی سایت اصلی دارد.
