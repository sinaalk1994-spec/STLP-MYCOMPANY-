# تهران‌ولت | Tehran Volt

اپ اندروید مدیران اتحادیه باتری و برق خودرو تهران. صفحهٔ شروع: **https://tehbatri.ir/admin**.

![آیکون تهران‌ولت](artwork/tehran-volt.png)

## نصب

فایل `dist/TehranVolt-1.0.1.apk` را روی گوشی اندروید ۸ یا بالاتر دریافت و باز کنید. نسخهٔ ۱.۰.۱ با همان نام بسته و کلید نسخهٔ قبلی امضا شده و به‌صورت به‌روزرسانی روی آن نصب می‌شود. در صورت درخواست اندروید، نصب از مرورگر یا فایل‌منیجر مورد استفاده را مجاز کنید. سپس با حساب فعلی پنل وارد شوید. برنامه به اینترنت و Android System WebView به‌روز نیاز دارد.

## تغییرات ۱.۰.۱

- متن و وضعیت طولانی خبر در کادر می‌شکند؛ دکمه‌های ویرایش و حذف در موبایل ردیف جداگانه در بالای کارت دارند.
- ناحیهٔ لمس دکمه‌های خبر روی موبایل به ۴۰ پیکسل افزایش یافته و نام قابل‌خواندن برای صفحه‌خوان دارد.
- فرم‌های ویرایش بلند داخل ارتفاع قابل‌مشاهده قرار می‌گیرند و اسکرول داخلی دارند.
- اصلاح با بارگذاری اخبار جدید و جابه‌جایی داخل سایت نیز اعمال می‌شود و به ذخیرهٔ محتوا یا مجوزهای حساب کاری ندارد.
- این تغییر از asset محلی اپ روی مبدا مجاز سایت اعمال می‌شود؛ انتشار روی سرور سایت نیاز نیست.

## امکانات

- اتصال به پنل واقعی سایت؛ نقش‌ها و سطح دسترسی همان حساب سایت است.
- نگهداری کوکی ورود مطابق انقضای تعیین‌شده توسط سرور؛ هیچ نام کاربری یا رمز عبوری در کد قرار ندارد.
- نمایش صفحه‌ها و جدول‌های فعلی سایت، با اسکرول افقی جدول‌های عریض.
- انتخاب فایل و عکس از انتخاب‌گر اندروید برای بارگذاری در سایت.
- ذخیرهٔ خروجی‌های PDF و اکسل با انتخاب محل ذخیره توسط کاربر؛ دریافت عادی تا ۱۰۰ مگابایت و خروجی Blob تا ۳۲ مگابایت.
- منوی بالای برنامه: بازگشت، صفحه اصلی پنل، بازخوانی و چاپ/ذخیرهٔ PDF صفحهٔ جاری.
- آیکون فارسی با زمینهٔ شیری و حاشیهٔ امن برای برش گرد و گوشه‌گرد.

## حریم خصوصی و امنیت

برنامه فقط مجوز اینترنت دارد؛ مجوز عمومی حافظه، دوربین، میکروفن یا مکان درخواست نمی‌کند. اطلاعات ورود مستقیماً به `https://tehbatri.ir` ارسال می‌شود. نسخهٔ پشتیبان داده‌های اپ غیرفعال است. لینک‌های خارج از دامنه با انتخاب کاربر در مرورگر یا برنامهٔ مربوط باز می‌شوند. هیچ رابط Java به JavaScript برای صفحات وب فعال نشده است. ابزار تحلیل رفتار یا تبلیغات اضافه نشده است.

## ساخت

پروژه مستقل از سایت Next.js است و کد اصلی ERP را در خود ندارد. نام بسته `ir.tehbatri.admin`، حداقل API 26 و API مقصد 35 است.

برای ساخت قابل تکرار در ویندوز، Java 17 و Android SDK Platform 35 و Build Tools 35.0.0 لازم است:

```powershell
./build.ps1 -JavaHome 'C:/path/to/jdk-17' -BuildTools 'C:/path/to/Android/Sdk/build-tools/35.0.0' -AndroidJar 'C:/path/to/Android/Sdk/platforms/android-35/android.jar'
```

اسکریپت تست‌ها را اجرا، منابع را با `aapt2` بسته‌بندی، کد را با `javac` و `D8` کامپایل، APK را با `zipalign` مرتب و با `apksigner` امضا و اعتبارسنجی می‌کند. Gradle project نیز برای باز کردن در Android Studio موجود است؛ Java 17 و Gradle 8.11.1 با AGP 8.10.1 استفاده شود. خروجی release در Gradle نیازمند تنظیم امضای خصوصی است.

کلید امضا و رمز محلی در `.signing/` ساخته می‌شوند و در مخزن قرار نمی‌گیرند. برای به‌روزرسانی قابل نصب روی نسخهٔ قبلی، همین کلید را به‌صورت خصوصی نگه دارید و نسخه را در manifest و Gradle افزایش دهید؛ اسکریپت نام APK را از manifest می‌گیرد.

## وضعیت بررسی

- صفحه‌های اصلی پنل واقعی پیش از ساخت در عرض‌های ۳۶۰ و ۳۹۰ پیکسل بررسی شدند؛ جدول‌های عریض اسکرول داخلی دارند.
- کد Java با SDK 35 کامپایل شده و ۴۲ بررسی UrlPolicy پاس شده است.
- APK با کلید release محلی امضا شده و امضا و zip alignment آن بررسی می‌شود.
- اصلاح چیدمان ۱.۰.۱ با دادهٔ ساختگی طولانی در عرض‌های ۳۲۰، ۳۶۰، ۳۹۰، ۶۴۰، ۷۶۸ و ۱۲۸۰ پیکسل آزمایش شده است. کارت‌های اضافه‌شده پس از بارگذاری و جابه‌جایی صفحه بررسی شده‌اند؛ فرم بلند در ارتفاع‌های ۸۴۴، ۵۶۰ و ۴۸۰ پیکسل در کادر مانده و اسکرول شده است. این آزمایش در مرورگر انجام شده و جای تست WebView گوشی را نمی‌گیرد.
- **تست روی گوشی واقعی هنوز انجام نشده است.** ورود، خروج، بارگذاری عکس و اکسل، ذخیرهٔ PDF و اکسل، کیبورد، چرخش صفحه و چاپ باید پس از نصب روی گوشی مدیر بررسی شوند.
- چاپ از منوی اپ برای صفحهٔ جاری است. پنجره‌های چاپ سفارشی سایت که از `window.print()` یا `window.open('about:blank')` استفاده می‌کنند نیازمند تست جداگانه‌اند.
- رفتار و چیدمان خود سایت از سرور دریافت می‌شود؛ این اپ کد سایت اصلی را تغییر نمی‌دهد. آیفون APK را نصب نمی‌کند؛ آیکون Add to Home Screen باید جداگانه در سایت اصلی منتشر شود.
